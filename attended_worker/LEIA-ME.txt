FECHAMENTO REST/DMS — ISS NET ONLINE (Goiânia/Aparecida de Goiânia)
=====================================================================

O portal do ISS Net Online bloqueia navegadores controlados por automação
(Playwright/CDP) via Cloudflare. Este script usa outro mecanismo — Windows
UI Automation — que só funciona DEPOIS que uma pessoa loga manualmente no
portal (certificado digital, qualquer verificação que aparecer). O script
não faz login sozinho: ele só mecaniza os cliques repetitivos de gerar e
salvar os PDFs/XMLs de cada empresa, dentro da MESMA janela que você já
autenticou.

INSTALAÇÃO (uma vez só, nesta máquina)
---------------------------------------
Pré-requisitos: Python 3.11+ instalado (baixe em python.org se não tiver),
Microsoft Edge instalado.

1. Extraia esta pasta em algum lugar fixo, ex.: C:\attended_worker
2. Abra o PowerShell nessa pasta e rode:

   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt

USO (toda vez que for fechar o mês)
--------------------------------------
1. Abra o Edge com a flag de acessibilidade (não é o atalho normal do
   navegador — sem essa flag o script não enxerga a página):

   Start-Process msedge -ArgumentList "--force-renderer-accessibility", "https://www.issnetonline.com.br/goiania/online/login/login.aspx"

   (troque "goiania" por "aparecida" conforme o município da empresa)

2. Faça login MANUALMENTE nessa janela: clique em "Logar com certificado
   digital", escolha o certificado, resolva qualquer verificação que
   aparecer. O script não participa dessa etapa.

3. Deixe essa janela do Edge em primeiro plano e NÃO mexa em outro app
   enquanto o script roda (ele clica em coordenadas/elementos da tela —
   se você trocar de janela no meio, quebra).

4. Rode o processamento - dois modos:

   MODO SINCRONIZADO COM O HUB (recomendado, só na máquina do escritório
   que tem acesso ao VPS - ver "SINCRONIZAÇÃO COM O HUB" abaixo): pega a
   lista de empresas que você já subiu na tela do Hub e devolve pra lá o
   status e os PDFs de cada uma - aparecem como botão de download no
   Hub, igual um módulo automatizado de verdade:

   cd C:\attended_worker
   .venv\Scripts\python.exe issnet_attended.py processar-hub "ID_DO_ESCRITORIO" "PASTA_ONDE_SALVAR"

   MODO OFFLINE (sem sincronizar nada, só gera os arquivos localmente):

   .venv\Scripts\python.exe issnet_attended.py processar-planilha "CAMINHO_DA_PLANILHA.xlsx" "PASTA_ONDE_SALVAR"

   Nos dois casos, a pasta de destino é organizada automaticamente como:
   PASTA_ONDE_SALVAR\{código da empresa}\{competência MMAAAA}\arquivo.pdf

5. No final aparece um resumo (OK/ERRO por empresa). Pra reprocessar só
   uma empresa específica (não sincroniza com o Hub, só testa):

   .venv\Scripts\python.exe issnet_attended.py testar-empresa "CNPJ" "CODIGO" "PASTA_ONDE_SALVAR"

SINCRONIZAÇÃO COM O HUB (modo "processar-hub")
--------------------------------------------------
Só funciona na máquina que tem a chave SSH de deploy do escritório (fala
com o super admin se não tiver) - sem ela, o script recusa com uma
mensagem clara, não trava escondido. Passos (uma vez só):

1. Copie a pasta ".deploy_keys" (com a chave "homehost_deploy") pra ficar
   como pasta IRMÃ desta ("attended_worker"), ex.:
     C:\algumlugar\.deploy_keys\homehost_deploy
     C:\algumlugar\attended_worker\issnet_attended.py

2. Gere attended_worker\prod.env com as credenciais de produção (peça o
   comando pro super admin - ele lê um arquivo .env no VPS via SSH, nunca
   precisa digitar senha nenhuma na mão).

3. A licença de uso desse modo pode ser ligada/desligada a qualquer
   momento pelo super admin, em Gerenciar Escritórios no Hub. Se estiver
   desligada, o script para com uma mensagem clara antes de fazer
   qualquer coisa.

LIMITAÇÕES CONHECIDAS
------------------------
- Exportar XML (quando há movimento) ainda não foi implementado/testado
  neste mecanismo — só o PDF do Livro Fiscal (DMS e REST).
- Sessão do portal expira depois de um tempo parado — se aparecer erro de
  "campo não encontrado", provavelmente precisa logar de novo.
- O clique no botão "Gerar" é por coordenada da tela — se a janela do Edge
  estiver com zoom/tamanho muito diferente do padrão, pode errar o alvo.
